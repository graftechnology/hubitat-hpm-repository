# Hubitat Package Manager Repository

## Graf Technology, LLC

Hubitat Package Manager Repository for Graf Technology, LLC

## Available Packages

### Notification Drivers

1. **ClearlyIP SMS Notification Driver**

   - A Hubitat driver that sends SMS notifications via the ClearlyIP Unity SMS API
   - Category: Notifications
   - Tags: Notifications

2. **NTFY Notifier Driver**
   - A comprehensive Hubitat driver for NTFY notifications (ntfy.sh or self-hosted)
   - Features: Connection testing, enhanced error handling, input validation, state management, tags/emojis, click actions, attachments, custom icons, markdown formatting, and message scheduling
   - Category: Notifications
   - Tags: Notifications, NTFY, Push
   - Documentation: [GitHub Repository](https://github.com/graftechnology/hubitat-ntfy-notification-driver)

## Installation

To use these packages in Hubitat Package Manager:

1. Open Hubitat Package Manager in your Hubitat hub
2. Go to "Package Manager" → "Browse by Tags" or "Browse by Category"
3. Search for "Graf Technology" or browse the "Notifications" category
4. Install the desired package
